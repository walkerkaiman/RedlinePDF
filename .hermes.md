# RedlinePDF

PDF annotation editor built with Tauri + Konva + pdf-lib.

## Build & Test

```bash
npm run build      # TypeScript check + Vite build
```

## Style

- Prefer `patch` for edits, `write_file` for new files
- Touch only what's needed — no drive-by refactors
- Match existing conventions; AGENTS.md wins over defaults

## Project Notes (Automatic)

After completing a meaningful change in this repo, update project notes in Obsidian:

- Path: `~/Documents/Obsidian/Hermes-Agent/Projects/RedlinePDF/`
- Append to `README.md`: what changed and current status
- Update `NEXT-ACTIONS.md`: any follow-up tasks or review items
- Add entries to `DECISIONS.md` if a durable decision was made

Keep notes concise — one line per entry. Do not edit files outside the Obsidian project folder. This happens automatically after each task. No user prompt needed.
